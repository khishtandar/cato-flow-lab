# Cato Flow Lab

An interactive study aid for Cato SASE traffic flows. Pick two points on a sample network (branches, HQ, remote users, a private app, cloud VPCs, the internet) and the lab draws the path through the Cato Cloud, MPLS or the open internet. It shows which features act on the flow (in Cato SPACE or at the edge) and links to the relevant Cato Knowledge Base articles.

Live: https://khishtandar.com/cato-flow-lab/

**Unofficial study aid, not affiliated with Cato Networks.** It is a simplified model built from Cato's public documentation; real behaviour depends on account settings and software version. The network, addresses and sites are fictional.

The whole lab is a single file, `index.html`, with no build step or server.
